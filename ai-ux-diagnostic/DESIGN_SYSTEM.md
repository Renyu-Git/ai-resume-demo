# AI 体验诊断台设计规范 V1.0

## 1. 设计原则

1. **信息优先**：界面服务于证据复核与问题判断，不使用无信息价值的装饰。
2. **色块分层**：卡片默认无描边、无阴影，使用背景色阶与间距建立层级。
3. **单一标准绿**：全产品只使用一个绿色 `#2EE55C`，用于品牌、成功、选中和当前状态，不再拆分浅绿与深绿。
4. **四点网格**：尺寸和间距均以 4px 为基础单位，禁止出现无依据的 5px、7px、10px、14px 等间距。
5. **层级稳定**：同一层级使用相同字号、字重、圆角和表面色，不因页面不同而改变。

## 2. 色彩系统

### 2.1 品牌绿色

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--brand` | `#2EE55C` | Logo、分析完成、复核案例、主按钮、选中状态、时间轴活动节点 |

品牌不建立浅绿、深绿或近似绿色阶。绿色底统一搭配 `--text-strong #151714`；Hover 只通过亮度变化表达，不新增色值。普通提示、诊断总结和问题卡使用中性色。

禁止使用：`#20C84C`、`#166B2E`、`#E2F8E7`、`#68EA86`、`#79EF95`、`#E5FAEA`、`#DFF6E4` 等第二套绿色。

### 2.2 中性色

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--surface-canvas` | `#EFEFEC` | 页面画布、工作区间隔 |
| `--surface-primary` | `#FBFBF9` | 主面板、内嵌内容块 |
| `--surface-secondary` | `#F1F2EE` | 普通卡片、默认控件 |
| `--surface-tertiary` | `#E8E9E4` | Hover、反馈区、较强层级差 |
| `--surface-selected` | `#ECEEE9` | 中性选中状态，避免大面积绿色 |
| `--text-strong` | `#151714` | 标题、关键数字、主操作文字 |
| `--text-default` | `#4F534D` | 正文、控件文字 |
| `--text-muted` | `#858A82` | 说明、时间、辅助信息 |
| `--text-disabled` | `#A2A69F` | 禁用、占位、弱提示 |

### 2.3 语义色

| 语义 | 背景 | 文字 | 使用范围 |
| --- | --- | --- | --- |
| 高风险 | `#FFF0EF` | `#BD3F3B` | 高风险标签、错误状态 |
| 中风险 | `#FFF4E8` | `#C76508` | 中风险标签、警示状态 |
| 低风险/完成 | `--brand` | `--text-strong` | 低风险标签、完成状态 |

语义色只用于状态标签、图标和必要提示，不铺满整张问题卡。

### 2.4 色彩比例

- 中性色：85%–90%
- 品牌绿色及其色阶：5%–10%
- 风险语义色：不超过 5%
- 单个视图内只允许出现 `#2EE55C` 一种绿色。

## 3. 字体与排版

### 3.1 字体栈

```css
Inter, "SF Pro Text", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif
```

中文以苹方/微软雅黑呈现，英文与数字优先 Inter。禁止在局部组件中单独指定其他字体。

### 3.2 字号层级

| 层级 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| Display | `42 / 46px` | 520 | 诊断记录页展示型标题，仅此场景使用 |
| Page title | `22 / 30px` | 650 | 工作台结果标题、弹窗主标题 |
| Section title | `16 / 24px` | 650 | 侧栏品牌、模块标题 |
| Card title | `14 / 22px` | 650 | 问题标题、项目标题 |
| Body | `13 / 21px` | 400 | 正文、问题描述 |
| Control | `12 / 18px` | 600 | 按钮、筛选、标签 |
| Caption | `11 / 17px` | 400 | 辅助说明、时间、状态 |
| Micro | `10 / 14px` | 400–600 | 数量、紧凑型徽标 |

### 3.3 字重规则

- `400`：正文、说明文字。
- `520`：仅展示型大标题。
- `600`：控件、标签、次级标题。
- `650`：页面标题、卡片标题、关键状态。
- `700`：仅风险序号或极少数关键数字。
- 禁止使用 `550`、`570`、`580`、`670`、`680` 等无体系字重。

### 3.4 排版规则

- 正文最小字号 11px；长段问题描述建议 12–13px。
- 中文正文行高不低于字号的 1.55 倍。
- 页面标题不使用负字距；数字可使用等宽数字特性。
- 单行按钮和标签不换行，正文优先自然换行。

## 4. 间距系统

| Token | 数值 | 常见用途 |
| --- | --- | --- |
| `--space-1` | 4px | 图标与短文本、紧凑状态间隔 |
| `--space-2` | 8px | 同组控件、内嵌模块间距 |
| `--space-3` | 12px | 卡片内边距、卡片之间的基础间距 |
| `--space-4` | 16px | 模块分组、标准面板内边距 |
| `--space-5` | 24px | 主面板内边距、标题与主体的大间隔 |
| `--space-6` | 32px | 页面级区域间隔、弹窗外边距 |

### 4.1 使用规则

- 工作台列间距：12px。
- 主面板内边距：24px。
- 普通卡片内边距：12px。
- 卡片列表间距：8px。
- 内嵌信息块间距：8px，内边距 12px。
- 图标与文字：8px；紧凑徽标可使用 4px。
- 禁止内容贴边；任何可读文本距离所属色块边缘至少 12px。

## 5. 圆角系统

| Token | 数值 | 用途 |
| --- | --- | --- |
| `--radius-inner` | 6px | 卡片内嵌信息块、缩略图 |
| `--radius-control` | 8px | 按钮、输入框、Tab、筛选器 |
| `--radius-card` | 8px | 主面板、问题卡、统计卡、项目卡 |
| `--radius-modal` | 12px | 弹窗 |
| `--radius-pill` | 999px | 状态胶囊、风险标记、圆形序号 |

嵌套关系固定为：外层卡片 8px，内层模块 6px。除弹窗和胶囊外，不允许出现 10px、14px、16px、18px、20px 等圆角。

## 6. 表面与边界

### 6.1 卡片

- 默认：无描边、无阴影。
- 画布 `surface-canvas` 上使用 `surface-primary` 主面板。
- 主面板内的普通卡片使用 `surface-secondary`。
- 卡片内部的信息块使用 `surface-primary`。
- 层级优先通过 8–12px 间距与色阶区分，不用边线圈出容器。

### 6.2 允许使用边界的场景

- 键盘焦点：2px 品牌绿焦点环，外偏移 2px。
- 时间轴当前缩略图：2px 品牌绿轮廓。
- 实际媒体边界：当浅色图片与画布无法区分时，可使用 1px 中性边界。
- 输入错误：可使用语义色边界，但正常状态保持无描边。

### 6.3 禁止

- 主面板外框内再套统计区外框。
- 问题卡外框内再用分割线切割每个字段。
- 使用阴影替代正常的信息层级。
- 同一模块同时使用描边、阴影和背景色三种分隔方式。

## 7. 组件规范

### 7.1 按钮

- 标准高度：38–40px；紧凑按钮：30–32px。
- 水平内边距：12px；图标与文字间距：8px。
- 主按钮：`--brand`；Hover 只调整亮度，不新增绿色。
- 次按钮：`surface-secondary`；Hover 使用 `surface-tertiary`。
- 禁用：`surface-secondary + text-disabled`，不降低到难以辨认的透明度。

### 7.2 Tab 与筛选

- 容器无描边，背景使用 `surface-primary` 或透明。
- 单项高度 30–32px，圆角 8px。
- 默认 `surface-secondary`，Hover `surface-tertiary`。
- 选中使用 `--brand + --text-strong`。
- “一键展开/收起”与筛选项保持同高度、同圆角、同字号。

### 7.3 统计卡

- 三张统计卡平铺，不再增加外层描边容器。
- 卡间距 8px，内边距 12px，圆角 8px。
- 默认底色 `surface-secondary`。
- 完成状态只在图标背景使用绿色，不整卡铺绿。

### 7.4 问题卡

- 默认与展开状态均为 `surface-secondary`，圆角 8px，无描边。
- 当前问题不使用绿色整卡背景，只将序号切换为 `--brand + --text-strong`。
- 标题区内边距 12px；展开内容与标题间不加分割线。
- 字段卡使用 `surface-primary`、6px 圆角、12px 内边距、8px 间距。
- 反馈区使用 `surface-tertiary`，保持 6px 内圆角。

### 7.5 证据面板

- 面板圆角 8px，和结果面板一致。
- 视频/变化证据 Tab 距面板顶部和左侧各 12px。
- Tab 容器 8px，内部按钮 6px，形成稳定的嵌套半径。
- 时间轴卡片圆角 8px；活动节点和缩略图只使用标准品牌绿。

### 7.6 徽标与风险标签

- 仅胶囊形组件使用 999px 圆角。
- 高/中/低风险必须使用语义色，不与品牌绿色混用。
- 专家复核、分析完成属于正向状态，使用品牌绿色色阶。

## 8. 交互状态

| 状态 | 视觉规则 |
| --- | --- |
| Default | 中性表面，无描边 |
| Hover | 背景提高一级：Secondary → Tertiary |
| Active/Selected | 局部使用 `--brand + --text-strong` |
| Focus | 2px `--brand` 焦点环，2px offset |
| Disabled | 中性背景 + Disabled 文字，保留可读性 |
| Loading | 保持组件尺寸，避免布局跳动 |
| Error | Danger 50 背景 + Danger 600 文字/图标 |

## 9. 图标规范

- 默认线性图标，线宽和视觉尺寸保持一致。
- 常规图标 16px；标题或关键状态 18–20px；微型标签 12–14px。
- 图标颜色继承当前文本或语义色，不单独增加新的绿色。
- 图标按钮必须有 `title` 或可访问名称。

## 10. 响应与密度

- 当前工作台最小宽度 1120px，低于该宽度不压缩字号。
- 结果列最小 520px，证据列最小 430px。
- 空间不足时优先减少非核心横向内边距，再考虑隐藏次要信息。
- 文本先换行，不通过缩小字号解决溢出。

## 11. 设计验收清单

每次发布前必须逐项检查：

- [ ] 页面只出现 `#2EE55C` 一种绿色。
- [ ] 问题卡没有大面积绿色背景。
- [ ] 卡片默认无描边、无阴影。
- [ ] 外层卡片为 8px，内嵌模块为 6px。
- [ ] 所有间距均来自 4/8/12/16/24/32px。
- [ ] 同级标题字号和字重一致。
- [ ] 主按钮、选中、成功状态使用同一品牌绿色色阶。
- [ ] 高/中/低风险使用语义色，不用品牌色代替风险色。
- [ ] 统计卡没有多余的外层描边容器。
- [ ] 正文距离色块边缘至少 12px。
- [ ] Hover、Focus、Selected、Disabled 状态完整。
- [ ] 1280px 与 1440px 视口下无贴边、遮挡、溢出或跳动。

## 12. 治理规则

1. 新组件只能引用本规范 Token，禁止直接写近似色和临时圆角。
2. 修改 Token 前先检查全局影响，不在单个页面覆盖品牌色。
3. 新增尺寸必须说明为何现有 4px 网格无法满足。
4. 视觉验收以浏览器渲染为准，测试和构建通过不能代替视觉复核。
5. 规范变更需同步更新本文件和 `src/styles.css`，版本号递增。
